A 4 KB chess engine in Python: 0x88 board, alpha-beta with quiescence, transposition table, killer moves, fixed node budget per move. `main.py` is a packed entrypoint made by the kit's `makefun compress`; the readable source travels with the entry bundle.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
